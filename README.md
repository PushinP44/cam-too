# cam-too

cam-too applies camera and film looks to photos.
Everything runs in your browser: no upload, no backend.
It is written in TypeScript with Vite and Preact.

## Quick start

```
npm install
npm run dev
```

Node 22.12 or newer (22.12+, 24, or 26+) is required.

The design spec is at [docs/superpowers/specs/2026-11-11-cam-too-design.md](docs/superpowers/specs/2026-11-11-cam-too-design.md).
